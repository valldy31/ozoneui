OzoneUI Help & Developer Wiki

Everything developers and AI coding agents need to install, customize, secure, and deploy OzoneUI on the open web.

Include ozone.css and ozone.js once in your document head. Every <oz-*> tag self-hydrates.

Use semantic <oz-grid cols="12"> with responsive tablet (span-md) and phone (span-sm) props, or CSS classes .oz-grid-12 + .oz-col-4.

Combine <oz-app-shell> + <oz-sidebar> for desktop admin sidebars (with automatic 900px mobile drawer), or <oz-bottom-nav position="fixed"> + <oz-fab position="bottom-right"> for mobile PWAs.

Any OzoneUI form element (<oz-select>, <oz-date-picker>, <oz-slider range>, <oz-combobox>, <oz-color-picker>, <oz-number-input>, <oz-otp-input>) with a name attribute syncs to native FormData automatically.

Share llms.txt or llms-full.txt with your assistant. In VS Code / Cursor, our included vscode.html-custom-data.json & dist/ozone.d.ts give instant tag and attribute IntelliSense across all 66 components.

OzoneUI eliminates remote Google Fonts requests (GDPR-safe), strips dangerous on*/javascript: vectors in <oz-renderer>, respects OS prefers-reduced-motion (EU Accessibility Act), and includes <oz-cookie-consent> + data-oz-gdpr="strict". See EU & GDPR Center.

Switch built-in component UI labels dynamically with Ozone.i18n.setLocale('bg') or override any phrase via Ozone.i18n.extend({...}) and per-card attributes (cta-label, unit, aspect="16/9", no-tilt). In PHP SSR apps, pass "href": "?view=feed" on <oz-sidebar> / <oz-bottom-nav> items and use <oz-button type="submit" name="action" value="save"> for zero-JS forms, plus .oz-h-scroll and .oz-no-print utilities.
